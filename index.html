    GiantChrono

    Stopwatch

    • Start / Pause toggles counting; Lap records a split; Reset returns to zero and clears laps.
    • A tap on the display triggers the secondary command chosen in Settings (Lap by default).
    • Set a start delay in Settings for an audible 3-2-1 countdown before the start.

    Views and gestures

    • Swipe vertically on the display — or use the top-left button — to switch between stopwatch and clock.
    • Tap 🔓 to lock the controls against accidental touches; hold anywhere for one second to unlock.
    • Digits stack one group per line in portrait; force a layout in Settings.

    Keyboard

    • Space start/pause · L lap · R reset · V/↑/↓ switch view

    About

    Free, open source, offline-first. No ads, no tracking: all data stays on your device.
